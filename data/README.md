# Dataset

The Spark AI Computer Vision assessment states that a small dataset containing
Normal and Defective product images will be provided.

The assessment dataset has not yet been received.

Raw assessment images should be placed inside this `data/` directory after
their structure and labeling format have been inspected.

The final dataset-loading strategy, class distribution, train/validation/test
split, augmentation policy, and class-imbalance handling will be determined
only after analyzing the provided dataset.

Raw dataset files are excluded from Git by `.gitignore`.
